# Suntar Bhavan Palitana

Suntar Bhavan is a popular Jain dharamshala located in Taleti, Palitana, Gujarat, near the base of the sacred Palitana hills. Established in 2021, it provides clean and affordable lodging for pilgrims and visitors. 

Justdial +2

Key Details

Location: Hastgiri Road, Taleti, Palitana, Gujarat 364270 

Accommodation: Air-conditioned (AC) and non-AC rooms with attached bathrooms, 24-hour hot and cold water, and basic furnishings. 

Bhojanshala: An on-site bhojanshala serves meals (including Navkashi, lunch, and Chovihar) at set timings for a nominal per-plate cost.

Amenities: Ample vehicle parking, indoor seating, and luggage assistance.

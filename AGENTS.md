# Project Guidelines

- Keep the application independently buildable with the standard scripts in `package.json`.
- Store website-owned media under `public/images`; do not introduce external asset-proxy paths.
- Do not edit `src/routeTree.gen.ts` manually. It is generated by TanStack Router.
- Keep secrets and private credentials out of browser code and version control.
- Run `npm run build` and `npm test` before committing production changes.
- Preserve unrelated working-tree changes and avoid rewriting published Git history.
